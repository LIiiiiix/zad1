# Система парковки с абонементами

## Описание
REST API для управления парковочными зонами, автомобилями пользователей и биллингом.
Проект демонстрирует работу с реляционной базой данных PostgreSQL через Spring Data JPA.

## Технологии
- Java 21
- Spring Boot 4.1.1
- Spring Web MVC
- Spring Data JPA + Hibernate
- PostgreSQL
- Lombok

## Структура приложения
- `model/` — сущности предметной области (User, Vehicle, ParkingZone, ParkingSession, ParkingPass).
- `repository/` — интерфейсы доступа к данным (Spring Data JPA Repositories).
- `service/` — бизнес-логика и операции над данными.
- `controller/` — REST-эндпоинты для взаимодействия с клиентом.

## Бизнес-операции
Реализованы следующие сложные операции, затрагивающие несколько сущностей:
1. **Регистрация авто на абонемент**: Привязка транспортного средства к действующему пропускающему билету с проверкой конфликтов.
2. **Продление абонемента**: Увеличение срока действия с расчетом стоимости по тарифам зоны.
3. **Перенос сессии между зонами**: Закрытие текущей парковки в одной зоне и открытие новой в другой с автоматическим пересчетом стоимости.
4. **Возврат средств за абонемент**: Деактивация абонемента и расчет компенсации за неиспользованные дни.
5. **Статистика пользователя**: Агрегированный отчет о тратах, количестве поездок и посещенных локациях конкретного клиента.

## Как запустить
1. Установите PostgreSQL.
2. Создайте базу данных `zad1_db` и пользователя `zad1_user`.
3. Обновите настройки подключения в `src/main/resources/application.yaml`.
4. Выполните сборку проекта (`mvn clean install`).
5. Запустите класс `Zad1Application`.
6. Используйте файл `test.http` или Postman для тестирования эндпоинтов.
